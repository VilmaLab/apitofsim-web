APi-ToF MS Simulation

{# clip the 25px left / 23px right white padding baked into the webp (1600x800) #} {% markdown %} This site allows you to configure and run simulations of an Atmospheric Pressure Ionization Time-of-Flight Mass Spectrometer (APi-ToF MS). You can adjust voltage settings, define the compound chain, select the instrument model, and modify constants and simulation parameters. The underlying tools are available on GitHub: * [The apitofsim package](https://github.com/VilmaLab/apitofsim) which you can use to run simulations. * [The apitofsim-resultviewer package](https://github.com/VilmaLab/apitofsim-resultviewer) which allows the same plots as are shown on this website after running apitofsim. A history of the simulator, which includes a bibliography with the original publications can be found on [the background section of the apitofsim documentation](https://vilmalab.github.io/apitofsim/background/). {% endmarkdown %} {% endcall %} {% call tab_content('voltagecontrols') %}
